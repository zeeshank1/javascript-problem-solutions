## ✅ How to Use

1. Clone the repository:
    ```bash
       git clone https://github.com/your-username/javascript-problem-solutions.git
       cd javascript-problem-solutions
    ```

2. Navigate to a specific problem category and explore the solutions.

3. Run a problem-solving file using Node.js:

   ```bash
   node easy/problem1.js
   ```
